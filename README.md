# FinanIA Inclusivo — versión 2

Aplicación educativa de práctica financiera, construida con Streamlit.

## Publicar en Streamlit Community Cloud
1. Sube `app.py`, `requirements.txt` y `README.md` al repositorio de GitHub.
2. En Streamlit Community Cloud selecciona el repositorio.
3. Rama: `main`.
4. Archivo principal: `app.py`.
5. Pulsa **Desplegar**.

## Secciones
- Inicio y navegación guiada
- Conozco el dinero
- Practico compras y calculo cambio
- Organizo ingresos y gastos
- Meta de ahorro
- Retos y juegos
- Preferencias de lectura y contraste

## Nota importante sobre los datos
Esta versión guarda movimientos y preferencias en la sesión de Streamlit. En una aplicación alojada en la nube, esos datos pueden reiniciarse cuando la sesión se reinicia o la aplicación se vuelve a desplegar. No introducir información personal, bancaria ni datos reales sensibles. Para uso persistente se debe integrar una base de datos alojada y protegida.

## Alcance
Es un prototipo educativo, no ofrece asesoría financiera, no se conecta a bancos ni realiza pagos. Las actividades son ejemplos y se pueden repetir.
